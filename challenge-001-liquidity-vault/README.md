# Contract Lab Security Challenges

A collection of educational smart contract security challenges designed to test vulnerability discovery, exploit analysis, and secure development skills.

## About

Contract Lab Security Challenges focus on understanding smart contract behavior beyond the code itself.

Each challenge explores:
- Contract logic
- Attack paths
- Hidden assumptions
- Security impact
- Secure fixes

## Challenges

### Challenge #1 — Liquidity Vault

A vulnerable educational smart contract challenge.

**Objective:**
Find the vulnerability, reproduce the exploit, explain the root cause, and propose a minimal secure fix.

**Status:** Active

## Rules

- Educational purposes only.
- No real funds are involved.
- Do not attack deployed projects or services.
- Follow the specific rules provided for each challenge.

## Security Philosophy

Finding a bug is only the first step.

Understanding why it exists, how it can be exploited, and how to prevent it is what creates stronger security.
